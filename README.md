# 🎮 Hangman Game

A simple text-based **Hangman Game** developed in **Python** as part of the **CodeAlpha Python Programming Internship**.

## 📌 Project Overview

This project is a console-based Hangman game where the player has to guess a randomly selected word one letter at a time. The player has a maximum of **6 incorrect attempts** to guess the complete word before the game ends.

The project demonstrates the use of Python fundamentals such as loops, conditional statements, lists, strings, user input, and the random module.

---

## ✨ Features

- Randomly selects a word from a predefined list.
- Uses a list of 5 predefined words.
- Allows the player to guess one letter at a time.
- Validates user input.
- Prevents duplicate letter guesses.
- Displays the current progress of the hidden word.
- Allows up to 6 incorrect guesses.
- Displays a winning or game over message.

## 🎮 How to Play

1. Start the game.
2. A random word is selected from the predefined word list.
3. Guess one letter at a time.
4. If the letter is correct, it will be revealed.
5. If the letter is incorrect, one attempt is deducted.
6. You have a maximum of **6 wrong guesses**.
7. Guess all letters correctly to win the game.
